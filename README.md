## Overview

vorflow_ex provides a working example of the [vorflow](https://github.com/rhugman/vorflow) package by [rhugman](https://github.com/rhugman) within a jupyter notebook. The current single example "KW" contains information licensed under the [Open Government Licence – Ontario](https://www.ontario.ca/page/open-government-licence-ontario)

### Prerequisites

- Python 3.12 or higher
- Jupyter Notebook or JupyterLab
- Git
- *see yml in env folder*
